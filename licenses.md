# Asset and code licenses

This site is a static portfolio. There is no package.json and no bundled app framework.

## Original work

Photographs, design images, logos, video, and custom HTML/CSS/JS are original work by Alexa Carmona unless a project credit on the site names a collaborator.

## Fonts

Body type uses the system stack `Helvetica Neue, Helvetica, Arial, sans-serif`. A small amount of UI type uses `Times New Roman, Times, Georgia, serif`. No webfont files are embedded, and no paid font foundry files are shipped with the site.

## Third-party libraries (Works flipbook only)

Loaded only when the Georgia Entertainment case study flipbook opens:

- [PDF.js](https://github.com/mozilla/pdf.js) 3.11.174 — Apache License 2.0, via cdnjs
- [StPageFlip / page-flip](https://github.com/Nodlik/StPageFlip) 2.0.7 — MIT License, via unpkg

## Form delivery

The About contact form posts to [FormSubmit](https://formsubmit.co) to email inquiries. FormSubmit is a hosted form endpoint, not a site dependency in this repo.

## Not used

No Google Fonts, Adobe Fonts, icon kits, stock UI kits, or non-open-source npm packages are included.
